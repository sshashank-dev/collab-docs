# CollabDocs

A real-time collaborative document workspace where multiple users can create, edit and manage documents together.

## 🚀 Live Demo

https://collab-docs-drab-psi.vercel.app/

## ✨ Features

- 🔐 User authentication
- 📝 Create and manage documents
- 👥 Real-time collaborative editing
- 🖱️ Live collaboration between multiple users
- 💾 Automatic saving
- 🔄 Real-time synchronization
- 📱 Responsive user interface
- 🌐 Full-stack REST API
- 🗄️ MongoDB database integration

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- Tiptap
- Vite
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Real-Time Collaboration
- WebSockets
- Yjs
- y-websocket
